RAG 기반 청년 정책 멀티에이전트 챗봇

온통청년 공공 API 기반 · 4개 도메인 전문 에이전트 · LangGraph 멀티에이전트 아키텍처

프로젝트 개요 시스템 아키텍처 에이전트 플로우 도메인별 기능 RAG 파이프라인 API 명세 팀 역할

1. 프로젝트 개요

청년 대상 정부 정책(주거·취업·교육·복지문화)을 사용자 의도에 맞게 자동 분류하고, 도메인별 전문 AI 에이전트가 맞춤 답변을 제공하는 챗봇 시스템.
온통청년 공공 API에서 수집한 정책 데이터를 PGVector에 임베딩하여 RAG 방식으로 검색·생성을 분리 처리합니다.

기술 스택

Python FastAPI LangGraph LangChain Next.js React Axios GPT-4o-mini text-embedding-3-large PostgreSQL pgvector

데이터 출처

온통청년 공공 API
youthcenter.go.kr

컬렉션명: youth_policy_all
임베딩 모델: text-embedding-3-large

주요 수치

도메인 에이전트: 4개
LangGraph 노드: 9개
청크 크기: 500자 / 오버랩 100자
유사도 임계값: 0.4 ~ 0.9 (도메인별)

4. 도메인별 차별화 기능

💼 취업(Employment) — D-day 기반 마감 필터

온통청년 API의 신청기간 구분(aplyPrdSeCd)과 날짜(aplyYmd) 필드를 이용해 마감·만료 정책을 자동 분류합니다. LLM 없이 순수 Python으로 처리합니다.

flowchart LR A["PGVector 검색\nk=10"] --> B{"유사도 필터\n≤ 0.85"} B --> C{"aplyPrdSeCd"} C -->|마감| D["❌ 제외"] C -->|상시| E["🟢 상시접수"] C -->|특정기간| F{"날짜 파싱\naplyYmd"} F -->|미래| G["🔵 D-N (날짜 마감)"] F -->|과거| H["🟡 ⚠️ 현재 신청 불가"] F -->|없음| I["통과 (safe default)"] E & G & H & I --> J["knowledge_base\n→ LLM"]

지원 날짜 포맷: YYYYMMDD, YYYY.MM.DD, 범위형 20250320 ~ 20250403

🏠 주거(Housing) — 자격 사전 진단

PGVector 검색 후 사용자 프로필(나이·지역·혼인 상태)과 정책 조건을 LLM 없이 비교하여 ✅ 자격 충족 / ❓ 확인 필요 / ❌ 미충족 3단계로 분류. 생성 노드는 분류 결과를 바탕으로 【추천 정책】/【추가 확인 필요】/【자격 미충족 안내】 구조로 답변을 작성합니다.

🌿 복지문화(Welfare) — 5항목 자격 교차 검증

나이·고용 상태·소득·지역·학력 5개 항목을 교차 검증하는 check_eligibility 도구 탑재. 사용자 프로필에 빈 항목이 있으면 유도 질문으로 정보를 수집한 후 재검증합니다. 신청 마감 계산을 위한 calculate_dday 도구도 탑재.

📚 교육(Education) — 의도 유형별 검색 전략 분기

inquiry_type에 따라 검색 전략이 달라집니다.

의도 유형전략
검색 (search)기본 RAG
추천 (recommend)사용자 프로필 포함 쿼리 강화
상세 (detail)k=2, 정밀 검색
비교 (compare)복수 정책 병렬 검색

역할별 유사도 임계값 분리: guest 0.9 / user 0.7
